# Assist Fallback Response

Заменяет стандартный ответ Home Assistant Assist («Done» / «Готово») на случайную фразу из вашего списка.

Начиная с версии 2.0 интеграция настраивается через интерфейс: **Настройки → Устройства и сервисы**. Блок в `configuration.yaml` больше не нужен.

## Установка

### Через HACS (пользовательский репозиторий)

1. HACS →Repositories → ⋮ (три точки) → **Add custom repository**.
2. Type: `Integration`, Repository: `tanat74/assist_fallback`.
3. Нажмите **Download** и перезапустите Home Assistant.

[![open in my.home-assistant.io](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=tanat74&repository=assist_fallback&category=integration)

### Вручную

Скопируйте содержимое репозитория в `custom_components/assist_fallback/` и перезапустите Home Assistant.

## Настройка

1. **Настройки → Устройства и сервисы → Добавить интеграцию** → `Assist Fallback Response`.
2. В поле **Фразы** впишите фразы, по одной на строке:

   ```text
   Что-то пошло не по плану.
   Не всё удалось выполнить как ожидалось.
   ```

3. Сохраните. Дальше фразы правятся кнопкой **Настроить** на карточке интеграции — изменения применяются сразу, без перезапуска.

Интеграция создаёт одну запись конфигурации: добавить вторую не получится, вместо этого правьте существующую.

## Языки и локализация

Фразы можно привязать к языку запроса. Начните строку с кода языка:

```text
ru: Что-то пошло не по плану.
en: Something didn't go as planned.
de-DE: Etwas ist schiefgelaufen.
```

Как выбирается ответ для запроса на языке `X`:

1. Фразы, указанные для `X` (или его базового языка, например `de` для `de-DE`).
2. Фразы языка Home Assistant из `configuration.yaml`.
3. Фразы без кода языка — они подходят для любого языка.
4. Встроенные фразы интеграции: `fallback_N` из `translations/<язык>.json`, при отсутствии — из `translations/en.json`.

Фразы с кодом языка имеют приоритет над строками без кода и не смешиваются с ними. Опция **Добавить встроенные локализованные фразы** добавляет к вашим фразам встроенные фразы того же языка.

Если ни для языка запроса, ни для языка Home Assistant фраз нет, Assist отвечает как обычно («Done»).

Свои переводы добавляются штатно для интеграций: файл `translations/<код_языка>.json` (например `translations/de.json`) с блоками `config` и `conversation.agent.fallback_N`. `strings.json` — эталонный текст для переводчиков, Home Assistant читает `translations/`. После добавления нового файла нужен перезапуск.

## Переход с configuration.yaml

Если блок остался в `configuration.yaml`, при первом запуске он автоматически импортируется в запись конфигурации, а в журнал попадёт предупреждение. После этого блок нужно удалить:

```yaml
assist_fallback:
  responses:
    - "Что-то пошло не по плану."
```

После импорта YAML игнорируется, все фразы живут в интерфейсе.

## Ограничения

- Работает только с встроенным разговорным агентом Home Assistant (заменяется ответ агента, когда действие не выполнено). Ответы LLM-агентов не меняются.
- Интеграция подменяет метод `DefaultAgent._handle_trigger_result`, поэтому после крупных обновлений Home Assistant стоит проверять, что интеграция загружается без ошибок.
- Максимум 50 фраз, каждая не длиннее 200 символов.
